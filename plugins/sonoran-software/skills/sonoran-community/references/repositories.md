# Official integration repositories

Use these repositories as implementation references when the current documentation alone is not enough:

- Sonoran CAD for FiveM: https://github.com/Sonoran-Software/SonoranCADFiveM
- Sonoran Radio for FiveM: https://github.com/Sonoran-Software/radio_fivem
- Sonoran CMS Core for FiveM: https://github.com/Sonoran-Software/sonorancms_core
- Sonoran CMS for Roblox: https://github.com/Sonoran-Software/Sonoran-CMS-Roblox-Integration
- Sonoran CMS for Minecraft: https://github.com/Sonoran-Software/Sonoran-CMS-Minecraft-Integration

Prefer the repository matching the user's game and product. Read the README and configuration entry points first, then inspect only files relevant to the requested integration.
